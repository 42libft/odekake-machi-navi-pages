# おでかけ待ち時間ナビ（GitHub Pages版）

スタッフが確認した受付番号・現在呼出番号をもとに、待ち時間の目安を端末内で表示する簡易案内です。

## 使い方

1. 待ち札の写真を選ぶ／撮影します。対応ブラウザのTextDetectorを試し、使えない場合は同梱の数字OCRへ自動で切り替えます。
2. OCR候補を確認し、違う場合や読めない場合は受付番号を手入力します。
3. 受付番号から39〜45組の初期目安を選び、現在呼出番号と待ち時間を表示します。
4. スタッフが現在呼出番号・待ち時間を必要に応じて上書きします。

## 大切なこと

- スタッフ作成／くら寿司公式ではありません／公式予約・順番待ちには接続しません。
- OCR候補と待ち時間は確定情報ではありません。必ずスタッフが確認してください。
- 写真と入力値は画面内だけで扱い、保存・外部送信しません。
- OCR worker・core・英語数字認識データはこのリポジトリに同梱しています。実行時に外部CDN・外部API・外部モデルを使いません。

## ローカル確認

```bash
npm ci
npm run build
npm test
npm run lint
```

GitHub Pagesのプロジェクトサブパスでも動くよう、静的ファイルの参照はビルド時のbase pathに合わせます。
